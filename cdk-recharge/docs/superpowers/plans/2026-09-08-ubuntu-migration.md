# Ubuntu 部署与数据迁移计划

**目标：** 将本机当前代码及 SQLite 一致性快照迁至用户指定服务器，保留本机原数据。

**架构：** Ubuntu 22.04 amd64 上安装官方 Docker Engine / Compose；独立目录 /opt/gpt-cdk，应用先只发布 127.0.0.1:8081，使用 SSH 隧道验证。域名和公网访问方式另待用户确认。

## 边界

- SSH 首次主机指纹已由用户确认；密码不写文件、日志或报告。
- 不删除、覆盖已有远端业务；不变更 SSH 认证和防火墙；不执行购买、兑换、退款、冻结。
- 本机仍可运行；当前同步是带时间点的快照，不是持续双向同步。正式切换前需用户停止本机写入并再次同步。
- 迁移完整数据库和必要运行配置，但不上传 Git 历史、安全审查报告及与项目无关文件。
- JWT 密钥随数据安全传输、权限0600；不输出任何真实凭证。
- 远端初始安装使用现有业务代码，安全审查的未修复项不会因为迁移自动消失。

## 任务与验收

- [x] 核验主机指纹、系统、资源、端口与目录空闲状态。
- [x] 安装 Docker 官方软件源和 Engine/Compose；验证 systemctl is-active docker 与 docker compose version。
- [x] 按白名单打包当前前后端源码，排除 .env、数据、Git、node_modules、dist；通过 SSH 加密传输；远端编译 amd64 镜像。
- [x] 使用 SQLite backup API 从只读挂载创建一致性快照；PRAGMA integrity_check=ok；保存所有业务表行数、快照时间和SHA-256。
- [x] 复制所需运行配置与数据密钥，限制目录0700和文件0600；经 SSH 上传，在启动前比较数据库SHA-256与表行数。
- [x] 使用专属Compose项目启动；确认健康检查、数据库已安装状态、项目名称、匿名后台401和数据卷路径。
- [x] 经 SSH 隧道验证网页资源；卡台连接仅做只读检查。记录上游白名单等未满足条件。
- [x] 保存部署、备份和回滚说明；等待域名及最终切换决定，不宣称公网切换已完成。
