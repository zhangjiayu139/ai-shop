# v1.4.30 定制升级

基线：本站 v1.4.29（ae46a6e）。上游正式 v1.4.30：`b28ea2f6a94a2ecd58b13c12766c9da30e179256`，2026-10-10 18:40（北京时间）发布。

## 合入与保留

- 代理补发沿用原码付款地区：本站已知缓存优先，未知时查询卡台并按 ID 精确匹配；查不到地区则返回 503，不发新码、不禁用旧码。补发地区写入新码缓存、响应及审计。
- 保留本站 `payment_country` 的指针语义：缺失/null 是未知，明确空串才是默认区。上游原实现将缺失字段视作空串的路径不直接照搬。
- 复用现有 `issuePrefsWithPaymentCountry`，地区与选卡偏好独立传递，不引入重复的 `agentSwapIssuePrefs`。
- 补发响应明确返回不同地区（含空串默认区）时，缓存真实地区、记录 `region_mismatch` 拦住后续补发，返回冲突并提示管理员核查，不禁用原码、不向代理交付错误地区新码。记录或缓存写入失败返回 500，不伪报正常成功。
- 增加 Pro 5x 续费标签和无 `plan_flow` 时的续费档识别；显式 flow 仍优先。已有 Pro 5x 账号可继续手动确认续费，不自动提交兑换。
- 不改 UI 布局、品牌、三步首页、凭证清空、详情默认展开、Grok/X 支持、异步保护、授权错误映射、路由、JWT、数据路径或依赖版本；无数据库迁移。
