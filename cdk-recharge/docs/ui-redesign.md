# 页面视觉改造

## 目标

将门户与运营后台调整为克制的业务工具界面。保留路由、API、权限、兑换与发码流程、品牌配置、主题选择及明暗切换。

## 设计依据

使用 ui-ux-pro-max 的 Minimalism & Swiss Style 和 Data-Dense Dashboard 建议。采用中性底色、清晰分区、无衬线字体、少量主色以及可见焦点。不采用检索结果中的营销 Hero 模板。

## 视觉规则

- 默认主题：白色内容区、浅灰页面背景、蓝色主操作。旧主题标识 terracotta 保留以兼容现有配置，显示名称调整为标准工作台。
- 后台默认使用 224px 侧栏；窄屏收成保留全部入口的图标导航，退出及主题入口仍可用。
- 门户首页使用服务清单与操作说明两栏；窄屏顺序排列。四个原服务及其操作步骤均保留。
- 正文使用系统无衬线字体；等宽字体仅用于代码与标识符，普通表格文字不使用等宽字体。
- 主要控件圆角 6px，内容区圆角 8px；移除默认渐变、浮动和入场装饰。状态提示保留文字与语义色。
- 公共控件规则集中于 frontend/src/workspace.css，主题配色保留在 style.css，主题元数据保留在 theme.ts。

## 验收范围

前端构建、已有安装状态回归测试、公共页面与后台只读导航、表单和弹窗、明暗切换以及窄屏布局。涉及真实卡台发码、兑换、扣费的操作不作为视觉验收动作。
