# CDK Shop

本目录存放 TaoAi CDK 自动售卖站项目，包括商城源码、脱敏部署工具、商品资料和项目文档。

当前线上站点：`https://shop.edujerry.icu`

## 目录结构

- `app/`：基于 Dujiao-Next v1.4.7 的完整源码及 TaoAi 定制修改。
- `deploy/`：部署、备份、发布和验证脚本；运行时生成的密钥与配置不会进入仓库。
- `assets/`：商品图片及图片生成提示词。
- `products/`：商品资料、详情 HTML 和本地商品合同。
- `docs/`：支付宝接入资料和部署运营交接文档。
- `store.example.json`：不含生产密钥的店铺资料示例。

上游源码基线：`dujiao-next/dujiao-next@47cc6207c6796ccfda0526a3708be39e1b59eba3`。

## 本地构建

具体构建命令及依赖要求见 [`app/README.md`](./app/README.md)。TaoAi 定制主要位于前后台品牌展示、上游宣传入口清理和默认邮件文案。

## 安全约定

- 不提交服务器密码、SSH 私钥、TOTP Secret 或恢复码。
- 不提交支付宝应用私钥、数据库密码、JWT 密钥等生产凭据。
- 配置文件只保留脱敏模板，生产配置通过服务器受限文件或环境变量维护。
- 不提交真实或测试卡密、数据库文件、备份、上传目录和构建产物。
