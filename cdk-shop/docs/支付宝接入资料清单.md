# TaoAi 支付宝接入资料清单

整理日期：2026-09-14。当前商店只开放展示，尚未配置真实支付宝支付。

## 一、现有个人收款码：人工核款方案

准备下面的资料即可继续配置人工收款流程；这不是自动到账、自动发卡接口。

- [ ] 支付宝收款码原图（PNG/JPG，清晰完整，不带付款成功截图）。
- [ ] 扫码后显示的收款方名称，供核对收款对象。
- [ ] 该码是否固定金额；若固定金额，是否为 ¥139。
- [ ] 可人工核实到账的时间，以及希望向买家承诺的处理时效。

核款必须以收款账户中的实际到账记录为准，不能只凭买家截图发卡。个人静态收款码本身没有给本商店提供可验证的交易通知，不能仅靠一张码图开启自动发卡。当前人工核款流程也尚未配置。

## 二、正式自动支付：优先准备支付宝官方接口资料

先登录支付宝开放平台，按真实经营主体和商品类目查看可申请的支付产品，并完成申请审核。网页应用、支付产品的开通状态和接口权限需要分别核对；不要把个人码或“已有 APPID”当作支付功能已经开通。

### 申请前先确认

- [ ] 账户主体：个人、个体工商户或企业。
- [ ] 是否有营业执照，以及店铺经营主体名称。
- [ ] 具体销售场景：线上销售 ChatGPT Plus 月订阅 CDK，¥139。
- [ ] 支付宝申请页要求的网站备案、经营资质或其他材料：按实际页面要求准备，由你直接提交给支付宝。
- [ ] 已开通/申请中的支付产品名称及审核状态。线上收银优先查看电脑网站支付、手机网站支付的适用条件；是否准入以支付宝当前审核为准。

### 审核和密钥配置完成后交接

| 资料 | 用途 | 说明 |
|---|---|---|
| 正式环境 APPID | 标识支付应用 | 不要使用沙箱 APPID 作为正式收款配置 |
| 支付产品名称与开通状态 | 匹配可用接口 | 提供控制台状态截图即可，遮盖无关个人资料 |
| 应用私钥 private_key | 签署支付请求 | 与上传至支付宝的应用公钥配对；以私密文件交接，不贴聊天 |
| 支付宝公钥 alipay_public_key | 验证支付宝通知签名 | 注意不是“应用公钥” |
| 收款主体名称及商户 PID | 核对收款对象 | PID 与 APPID 不同 |
| 当前支付费率、结算规则 | 配置运营口径 | 以实际签约结果为准；默认买家实付 ¥139，不额外加收支付手续费 |

签名使用 RSA2。密钥尚未生成时可以等到接入阶段由我协助生成，你负责在支付宝控制台配置应用公钥。若使用证书模式，保留下载的应用公钥证书、支付宝公钥证书和支付宝根证书，届时根据当前系统字段处理。

## 四、若决定通过支付服务商接入

先提供服务商名称、官网、接入文档及结算方式供核验，不必先购买陌生易支付服务。确认后通常需要网关地址、商户 ID、协议版本及对应密钥/公私钥。易支付是接口协议名称，本身不能证明服务商信誉或资质。

## 五、不用提供的资料

不需要支付宝登录密码、支付密码、短信验证码或浏览器 Cookie。身份证和银行卡等入驻资料由你直接提交至支付宝，不需要发给我。应用私钥或接口密钥届时通过本机私密文件交接。

真实 CDK 属于正式发货准备资料，和支付宝开户资料分开准备。正式开放交易前还需完成支付签名、金额/收款方、重复通知和卡密交付权限验证。
