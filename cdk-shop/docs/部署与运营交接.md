## 登录与后续准备

后台地址及初始账号密码在 `.private/后台登录资料.md`，本机目录权限 700、文件权限 600。前台“登录”是买家入口，管理商店请使用私密文件内的专用后台地址。首次登录后请修改密码并启用后台两步验证。项目自身首次登录可能要求阅读运营声明，留给店主本人阅读确认。

正式销售还需要：

1. 提供真实 CDK 清单，确认兑换期限并留出商店专用库存，避免同一码在多个渠道同时售卖。
2. 确定支付宝收款方案。目前只有个人静态收款码，尚未提供码图或支付接口；它本身不能向网站提供可验证的到账回调。可先采用人工核实到账的流程，或接入有签名回调的正规支付宝支付渠道。当前未实现或启用个人码自动监控。
3. 若需要注册、密码找回或邮件发卡，配置 SMTP。当前注册和邮件发送关闭；正式销售可先选择游客下单查单。

开放购买前，先配置并验证支付渠道与真实库存，再移除 `/opt/gpt-cdk/Caddyfile` 中本商店域名块内的 `@salesDisabled` 和对应 handle 段，校验后平滑重载 Caddy，并更新开店公告。不要只开启下单入口而跳过支付验证。

上线交易前仍需验证：支付签名、订单金额和收款商户、重复通知不重复发卡、买家订单及卡密访问权限。当前未进行真实付款、退款或兑换测试。

## 部署结构与保护

- VPS：216.167.7.10；目录：`/opt/taoai-shop`；Compose 项目：`taoai-shop`。
- Dujiao-Next 官方 v1.4.7，源提交 `47cc6207c6796ccfda0526a3708be39e1b59eba3`。
- 官方 Linux amd64 压缩包 SHA256：`4528ffdae52a9ebcc893fdd08f250f59c83b633686414b33a4d9f810459a04f5`。
- 容器：`taoai-shop-app`、`taoai-shop-postgres`、`taoai-shop-redis`。数据库和缓存为独立实例与数据卷，均未发布宿主机端口。
- 商店进程以非 root 身份运行，根文件系统只读，移除 Linux capabilities，设置资源和日志限制。
- 管理员账号、密码、应用密钥及两类 JWT 密钥分别生成；没有使用默认管理员密码。上传禁用 SVG，仅允许常规图片格式。
- 内部数据库网络与反向代理网络分离；商店只信任 Caddy 在专用网络上的固定地址 172.21.0.2/32。
- 已追加 HTTPS 路由并持久化 Caddy 的专用网络连接；只重载 Caddy，不重建原容器。
- `.env`、配置文件等敏感路径返回 404；后台接口要求管理员认证。
- 现有六个业务容器 ID、StartedAt、RestartCount 与部署前一致；CDK 和 API 网站复验 HTTP 200。
- SSH 使用独立运维账号 `taoaiops` 和密钥认证，已关闭 root 远程登录及密码认证；本地端口转发仅允许访问服务器回环地址的 2053、2096 端口。UFW 与 Fail2ban 已启用，用于限制入口端口并封禁重复失败的 SSH 登录。

这里是部署保护与针对性验收，不代表对上游全部代码和依赖做过完整安全审计。后续升级仍需先备份并核对官方发布说明。
